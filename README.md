# Jadwal Kuliah — WELKOM BEKKKK

Project React + Vite + Tailwind CSS + lucide-react.

## Menjalankan di VS Code

1. Buka folder project ini di VS Code.
2. Buka Terminal.
3. Jalankan:

```bash
npm install
npm run dev
```

4. Buka alamat localhost yang diberikan Vite (biasanya http://localhost:5173).

## Build production

```bash
npm run build
```
